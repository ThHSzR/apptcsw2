# Histórico de versões

Todas as mudanças importantes deste projeto serão documentadas neste arquivo.

## 1.0.0 - 2026-10-22

Primeira versão funcional do aplicativo.

### Incluído

- Projeto atualizado para Expo SDK 58.
- Telas de Login, Cadastro, Início e Perfil.
- Navegação Stack e Bottom Tabs com React Navigation.
- Abas de Busca e Pedidos com telas provisórias.
- Formulários controlados com React State.
- Validação de confirmação de senha.
- Passagem de parâmetros para a tela Perfil.
- Logout com limpeza do histórico de navegação.
- Tema de cores compartilhado.
- Layouts responsivos com Flexbox e ScrollView.
- Ícones Ionicons na barra de navegação.
- Configuração do ESLint.
- Testes manuais completos em dispositivo Android conectado por ADB.
